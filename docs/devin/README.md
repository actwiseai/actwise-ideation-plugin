# Install in Devin

Devin Desktop and Devin Local may expose different MCP setup surfaces. Add Actwise Ideation as a remote HTTP MCP server using:

```text
https://actwise.ai/ideation/mcp/v1
```

Complete browser authentication when the external sign-in page opens. Refresh the MCP tools or start a new session after connecting.

For environments that cannot accept a native remote URL, use the client-supported remote MCP bridge documented by Devin. Do not add tokens or client secrets to repository configuration.
