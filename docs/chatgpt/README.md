# Install in ChatGPT

## Plugin repository

Add the repository marketplace in Codex:

```bash
codex plugin marketplace add actwiseai/actwise-ideation-plugin
codex plugin add actwise-ideation@actwise
```

In ChatGPT, open the Plugins Directory, select the Actwise source, install Actwise Ideation, and complete browser authentication.

## Direct UI connection

In ChatGPT developer mode, add a remote MCP connection using:

```text
https://actwise.ai/ideation/mcp/v1
```

Complete browser authentication, start a new conversation, and select Actwise Ideation from the tools menu.
